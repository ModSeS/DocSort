The program is designed to automatically sort scanned documents. It determines the type of document (order, contract, act, application, etc.), extracts the number, date, and subject from the text, and then renames the file according to the specified pattern and places it in the appropriate folder. The program works with PDF, DOCX, DOC, JPG, PNG, TIFF, and BMP files. Text recognition is performed using artificial intelligence that analyzes the document image. Additional processing of the detected text is used to refine the results. The user configures file name templates through the graphical interface, specifies folders for incoming and sorted documents, and views the processing results. Documents that the program fails to recognize are placed in a separate folder for manual processing. Background operation is possible with periodic checking of the incoming folder. The result is an organized folder with clear file names.
Developed by Artur Rashitov.

Программа предназначена для автоматической сортировки отсканированных документов. Она определяет тип документа (приказ, договор, акт, заявление и т. д.), извлекает из текста номер, дату и предмет, а затем переименовывает файл по заданному шаблону и перемещает его в соответствующую папку. Программа поддерживает работу с файлами форматов PDF, DOCX, DOC, JPG, PNG, TIFF и BMP. Распознавание текста осуществляется с помощью технологий искусственного интеллекта, анализирующих изображение документа; для уточнения результатов применяется дополнительная обработка распознанного текста. Пользователь настраивает шаблоны имен файлов через графический интерфейс, указывает папки для входящих и отсортированных документов, а также просматривает результаты обработки. Документы, которые программе не удалось распознать, помещаются в отдельную папку для ручной обработки. Возможна работа в фоновом режиме с периодической проверкой папки входящих документов. В результате формируется упорядоченная структура папок с файлами, имеющими понятные и систематизированные названия.
